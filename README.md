## 🌟 Overview

**CHITHIRABHARATHAM (சித்திரபாரதம்)** is an interactive, museum-grade digital cartography dedicated to the preservation and exploration of **16 canonical Indian art traditions** spanning ten thousand years.

Built entirely as a **self-contained single-file web application (`index.html`)**, it brings together geospatial cartography, high-resolution museum photography, 2.4x interactive magnifying loupes, dynastic patronage archives, authentic pigment chemistry, an evolutionary chronological timeline, and an analytical comparative matrix.

---

## 🏛️ Key Experience Modes

### 1. Starting Intro Page (`#viewIntro`)
- **Masterpiece Hero Narrative**: Features the classical Cinzel display title, curatorial super-badge (`EDITORIAL CARTOGRAPHY • 10,000 BCE TO PRESENT`), and an editorial epigraph welcoming scholars and seekers.
- **Single-Line Action Cluster**: Instant one-click gateways to `Enter the Interactive Atlas`, `Exhibition Gallery`, `Timeline Odyssey`, and `Comparative Matrix`.
- **Heritage Statistics Ledger**:
  - **16** Canonical Art Traditions across 14 States & Territories.
  - **10,000+** Years of Preserved Lineage (Mesolithic Era to Modern Day).
  - **100%** Verified Real Museum Photography & Accession Provenance.
  - **4** Specialized Cartographic Projections & Day/Night Viewing.
- **Curatorial Highlights Showcase**: A balanced single row of four diverse flagship traditions:
  - *Ajanta & Ellora Caves* (Murals & Frescoes • Classical)
  - *Thanjavur (Tanjore)* (Bronze & Sculpture • Medieval)
  - *Madhubani (Mithila)* (Folk Scrolls & Textiles • Living Folk)
  - *Bhimbetka Rock Shelters* (Rock Art • Prehistoric)
- **Four Experience Gateways & Footer Launcher**: Direct access cards to every analytical dimension in the suite.

### 2. Interactive Geospatial Atlas (`#viewAtlas`)
- **Cartographic Hearth Pins**: Custom SVG map pins with tradition-specific pigment colors, gold rings, and smooth scale animations.
- **Cultural Influence Arcs**: Dynamic animated parabolic bezier curves illustrating regional artistic transmissions (e.g., *Ajanta frescoes $\rightarrow$ Lepakshi Vijayanagara murals*, *Mithila ritual folk $\rightarrow$ Puri Pattachitra scrolls*).
- **Heritage Explorer Sidebar**: Collapsible left-hand index with instant real-time search, historical era filter (Prehistoric, Classical, Medieval, Imperial, Living Folk, Modern), and artistic medium chips.
- **Interactive Map Popups**: Real photography preview cards featuring a dedicated terracotta **"View Exhibition Dossier"** button that flies the map and unfolds the side panel.

### 3. Exhibition Dossier Drawer (`#exhibitionDrawer`)
- **Real Photography Showcase**: Positioned prominently directly above *Historical Lineage & Patrons*:
  - Curatorial accession badge and authentic artifact provenance tag.
  - High-definition museum photography loaded from permanent CDN links with zero local file dependencies.
  - **Interactive 2.4x Magnifying Loupe**: Move your cursor over the artifact to inspect micro-details, mineral pigments, gold leaf gilding, and metal patinas.
  - Accession metadata card specifying the masterwork title, date, medium, and state.
- **Historical Lineage & Royal Patrons**: Exhaustive dynastic histories covering Mauryan, Gupta, Vakataka, Chola, Vijayanagara, Mughal, and Maratha patronage.
- **Masterwork Analysis**: Curatorial breakdown of aesthetic philosophy, *Tribhanga* postures, and symbolic iconography.
- **Authentic Pigments & Materials**: Mineral chemistry and raw preparation techniques (Badakhshan lapis lazuli, red ochre *geru*, malachite, cinnabar, vermilion, soot lampblack, and gum binders).
- **Cross-Tradition Influence Links**: Clickable cards that immediately pan and zoom the atlas to related cultural hearths.

### 4. Curator's Exhibition Gallery Grid (`#viewGallery`)
- High-definition responsive gallery showcasing all 16 canonical masterworks categorized by artistic genre:
  - *Murals & Frescoes*
  - *Bronze & Sculpture*
  - *Court Miniatures*
  - *Folk Scrolls & Sacred Textiles*
  - *Prehistoric Rock Art*

### 5. Chronological Odyssey Timeline (`#viewTimeline`)
- A continuous, unbroken 10,000-year vertical timeline tracing visual developments from Upper Paleolithic ochre petroglyphs through classical Buddhist frescoes and medieval bronze casting to colonial Kalighat satire and the modern Bengal revival.

### 6. Comparative Style Matrix (`#viewComparator`)
- Side-by-side analytical appraisal table allowing users to select any two regional schools and compare:
  - *Masterwork Photographic Artwork*
  - *Geographic Region & Coordinates*
  - *Epoch, Century & Dynastic Patrons*
  - *Ground Medium & Binding Preparation*
  - *Authentic Sourced Pigments*
  - *Theological Aesthetic Philosophy*
  - *Iconic Masterpiece Composition*

## 🚀 Quick Start & Usage

Because **CHITHIRABHARATHAM** is completely self-contained in a single file (`index.html`), it requires **no build pipeline, no compiler, and zero `node_modules`**.

### Option 1: Direct Browser Launch
Simply double-click `index.html` or open it directly in any modern web browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### Option 2: Local HTTP Server (Recommended)
Running through a local web server ensures optimal rendering of web fonts and map tile caching:

```bash
# Using Python 3
python -m http.server 5173

# Or using Node.js npx
npx serve .
```

Then open `http://localhost:5173` in your browser.

## 🛠️ Technology Stack

- **Markup & Structure**: Clean Semantic HTML5.
- **Styling**: Vanilla CSS3 with custom design tokens, CSS variables, glassmorphism, responsive grid & flexbox layouts, and custom scrollbars.
- **Cartography Engine**: [Leaflet.js](https://leafletjs.com/) (v1.9.4) with custom GeoJSON coordinate mapping and parabolic bezier SVG influence lines.
- **Typography**: Editorial museum fonts via Google Fonts:
  - *Cinzel* (Roman monumental display serif)
  - *Cormorant Garamond* (Classical scholarly serif)
  - *Plus Jakarta Sans* (Clean, legible UI sans-serif)
- **Vector Iconography**: [Lucide Icons](https://lucide.dev/).
- **Imagery**: Curated, authenticated museum photographs served via Cloudflare-backed CDN URLs.
